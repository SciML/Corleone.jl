CorleoneOED

CorleoneOED designs controls and measurement schedules for local parameter estimation in differential-equation models. It augments a Corleone ShootingLayer with state sensitivities and Fisher information, evaluated at nominal physical parameter values. Estimated parameters and tunable design variables are distinct.

Start here

Install CorleoneOED and OrdinaryDiffEqTsit5 for layer evaluation; the worked optimization tutorials also import their optimizer, packing, and plotting packages. Start with continuous Lotka–Volterra design to optimize fishing and two measurement densities. Then choose:

  • Discrete compartmental design to allocate relaxed weights to candidate observations.
  • Multiple experiments to combine independent designs and a global prior.

Guides and reference

Measurements and information defines grids, sensitivities, noise conventions, budgets, and criteria. Constructing and optimizing designs covers controls, augmented shooting, constraints, and priors. Numerical scope explains SVD reduction, DAE assumptions, and AD support. Exact signatures are in the API reference; references and attribution record scientific and software sources.

For shared layer construction, read Corleone's shooting guide. To build this sublibrary's manual, follow the build instructions.
