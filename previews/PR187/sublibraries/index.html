CorleoneInverse

CorleoneInverse fits shared model parameters and experiment-specific controls or initial states to observations. From the repository root, set up the example environment and run the introductory Lotka–Volterra fit:

julia --project=lib/CorleoneInverse/examples -e 'using Pkg; Pkg.develop([Pkg.PackageSpec(path="."), Pkg.PackageSpec(path="lib/CorleoneInverse"), Pkg.PackageSpec(path="lib/CorleoneOED")]); Pkg.instantiate()'
julia --project=lib/CorleoneInverse/examples lib/CorleoneInverse/examples/lotka_plain/main.jl

The parameter estimation guide starts with a one-parameter fit and shows how to warm-start a fit when adding an experiment.

CorleoneOED

CorleoneOED adds optimal experimental design to Corleone's shooting workflow. Use it to design controls and measurement schedules for local parameter estimation.

Start with the CorleoneOED overview for installation and the worked design tutorials. Its guides cover measurement conventions, design constraints, and numerical scope.
