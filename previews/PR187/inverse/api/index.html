API reference

Observations, experiments, predictions, and residuals are documented in the core API reference.

CorleoneInverse.ParameterEstimate — Type
struct ParameterEstimate{__T_x, __T_covariance, __T_std_errors, __T_confidence_intervals, __T_level, __T_rss, __T_dof}

Asymptotic statistics of a least-squares fit in natural parameter coordinates, in the packed order of the Lux parameters.

Fields

  • x: The natural parameter values.

  • covariance: The covariance matrix.

  • std_errors: The standard errors.

  • confidence_intervals: The (lower, upper) confidence interval of each parameter.

  • level: The confidence level 1 - α.

  • rss: The observation residual sum of squares.

  • dof: The residual degrees of freedom.

CorleoneInverse.mean_squared_residual — Function
mean_squared_residual(model)
mean_squared_residual(model, ps)
mean_squared_residual(model, ps, st)

Return the mean squared observation residual across all experiments. Each observed value counts once, with the same noise scaling as residual. Priors and shooting constraints are excluded. With no observed values, the result is NaN.

Evaluate the prediction once and sum over observation groups without concatenating their residual vectors. Parameters and state default to those retained by the model.

CorleoneInverse.residual_jacobian_sparsity — Function
residual_jacobian_sparsity(model; vectorize = default_vectorizer(), ps = model.ps, st = model.st)

Return the Boolean Jacobian pattern of residual(model, ps, st) for a prepared ODE experiment fit. Rows follow residual order and columns follow pack(vectorize, ps). The pattern excludes prior and constraint rows. Rebuild it after changing the packing, schedule, saved grid, or observation layout.

Corleone.CorleoneDynamicOptProblem — Method
CorleoneDynamicOptProblem(
    shooting,
    experiments,
    constraints;
    ps,
    st,
    rng,
    lcons,
    ucons,
    reducer,
    eval_module,
    evaluator,
    observation_parameters
)

Build CorleoneDynamicOptProblem(shooting, experiments, constraints...; ps, st, lcons, ucons, reducer = mean, observation_parameters = (;), eval_module, evaluator) from an Experiments container or observation Experiment, tuple, or NamedTuple. Lux parameters and state follow their owner, initialized once when omitted.

The reducer receives the squared, noise-scaled observation residuals in residual order and returns a scalar. The default is Statistics.mean. Pass reducer = x -> sum(x) / 2 for the Gaussian half-sum convention. Annotation priors add their negative log density once per owned value, outside the reduction. Observable selectors accept state symbols/indices, (u, p, t) -> value callbacks, or scalar Julia expressions such as :(p₁ * u₁). Expressions use current-time signal names and the independent variable; each observation supplies its own sampling grid. They compile once against the experiment's symbolic metadata. eval_module resolves custom helpers.

observation_parameters = (w = Tunable(default = 0.5), offset = Constant(default = 0.0)) declares shared observation-only values. Numeric declarations are shorthand for unbounded tunables. The fit creates an EvaluationLayer at model.layer.evaluation. The prepared parameter tree stores the shooting values in model.ps.shooting and the extra tunables in model.ps.evaluation. Constants are stored in model.st.evaluation. If supplied, ps and st are the shooting or experiments owner's Lux setup values.

A tagged constraint :experiment => :(u₁(2.0)) evaluates on that experiment. Untagged expressions apply to a single experiment. Callbacks receive the complete NamedTuple or tuple of trajectories; tagged callbacks receive one trajectory. Constraint bounds and automatic shooting equalities follow the ordinary dynamic optimization interface. Reconstruct the model after changing observation times, selectors, schedules, or saved layouts. Observation values and noise arrays remain referenced by the prepared model.

SciMLBase.NonlinearLeastSquaresProblem — Method
NonlinearLeastSquaresProblem(
    model;
    ps,
    st,
    vectorize,
    kwargs...
)

Construct a residual least-squares problem from an experiment CorleoneDynamicOptProblem. The prepared observation maps and sampling indices are reused. Untransformed Normal priors add residual rows. Finite parameter bounds are passed as lb and ub in internal coordinates; NonlinearSolve honors them natively or through a bounds transform. General priors and constraints use OptimizationProblem(model, ad).

ps supplies the initial unknowns and st becomes the SciMLBase problem's parameter p. Both default to the model's retained values. A replacement state must match the prepared schedules and layouts. Remaining keywords are forwarded to the SciMLBase problem.

SciMLBase.OptimizationProblem — Method
OptimizationProblem(
    shooting,
    experiments,
    ps,
    st,
    ad;
    vectorize,
    eval_module,
    evaluator,
    reducer,
    observation_parameters,
    kwargs...
)

Prepare an experiment dynamic problem and use Corleone's common Optimization.jl bridge for its observation loss, priors, bounds, and shooting constraints. reducer selects the scalar reduction of the squared observation residuals. Additional user constraints can be declared with CorleoneDynamicOptProblem directly.
