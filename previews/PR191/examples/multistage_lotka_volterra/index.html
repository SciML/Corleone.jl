Multistage Lotka–Volterra with a third species

This example splits the Lotka–Volterra fishing problem into two stages. The first stage optimizes the classic two-species fishery on $[0, 12]$. At $t = 12$ a third species (a superpredator) is introduced, and the second stage optimizes the three-species system on $[12, 24]$.

What you will learn

How to compose several ShootingLayers with the Stages container and connect them by a StageTransition. The example builds on the fishing tutorial.

Dynamics

The first two states are prey and predator populations; the fishing control v enters both equations. The third state accumulates the squared deviations of the populations from one. The stage duration $T$ scales the right-hand side, so both stages live on the normalized time $\tau \in [0, 1]$:

\[\begin{aligned} \dot{x} &= T(x-xy-c_1vx), & \dot{y} &= T(-y+xy-c_2vy),\\ \dot{J}_1 &= T\bigl((x-1)^2+(y-1)^2\bigr), & 0&\le v\le1. \end{aligned}\]

The parameter vector of the first stage is p = [T, v, c₁, c₂].

function lotka_two_species(du, u, p, t)
    x, y, cost = u
    T, v, c₁, c₂ = p
    du[1] = T * (x - x * y - c₁ * v * x)
    du[2] = T * (-y + x * y - c₂ * v * y)
    du[3] = T * ((x - 1.0)^2 + (y - 1.0)^2)
    return nothing
end

In the second stage the superpredator $x_3$ preys on the predator. With $\dot{x}_3 = T x_3 (y - x_3 - c_3 v)$ the triple $(1, 1, 1)$ is a steady state at $v = 0$. The cost accumulator continues from the first stage and adds the third species' deviation. Its parameter vector is p = [T, v, c₁, c₂, c₃].

function lotka_three_species(du, u, p, t)
    x, y, x3, cost = u
    T, v, c₁, c₂, c₃ = p
    du[1] = T * (x - x * y - c₁ * v * x)
    du[2] = T * (-y + x * y - c₂ * v * y)
    du[3] = T * (x3 * (y - x3 - c₃ * v))
    du[4] = T * ((x - 1.0)^2 + (y - 1.0)^2 + (x3 - 1.0)^2)
    return nothing
end

    f = Figure(size = (1000, 750))
