    Available problems#

    The registry contains the following constructors. Links open the implemented dynamics, objective, bounds, and constraints. The MINTOC links provide related mathematical formulations and reference solutions. Implemented control bounds, horizons, or continuous relaxations may differ; use the source definition when interpreting a benchmark result. Horizons are in each model's physical time coordinate; the input grids remain normalized to [0, 1].

    Select a subset by its registry identifiers before calling run_all:

    using OptimalControlBenchmarks

catalog = load_benchmarks()
selected = filter(problem -> nameof(problem) in (:lqr, :van_der_pol), catalog)

    Start with lqr to check the solver setup. Use the linked definitions to choose other models and suitable grids; the shared driver does not guarantee that its default initial guess or optimizer settings solve every problem.
