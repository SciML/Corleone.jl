    LTI Control with Unknown Coefficients#

    Prerequisites: the ModelingToolkit tutorial and basic linear systems. This problem adds terminal equalities and a feasible multiple-shooting guess. We jointly optimize a scalar input and three constant coefficients in \(\dot{x} = A x + b u\), with \(x(0)=0\) and \(x(10)=[3,1,-2]^T\). The objective is minimum control energy, \(\frac12\int_0^{10}u(t)^2\,dt\).

    using Corleone, ModelingToolkit
using ModelingToolkit: t_nounits as t, D_nounits as D
using OrdinaryDiffEqTsit5
using ComponentArrays, ForwardDiff, Optimization, OptimizationMOI, Ipopt
using LuxCore, Random, LinearAlgebra

    Model#

    The state is \(x\in\mathbb{R}^3\) and the input is scalar. The matrix and input vector are

    \[A=\begin{bmatrix}0&1&0\\a_1&0&1\\0&0&a_2\end{bmatrix}, \qquad b=\begin{bmatrix}b_1\\0\\1\end{bmatrix}.\]

    Bounds are \(-0.5\le a_i\le-0.05\), \(0.1\le b_1\le1\), and \(|u|\le3\). Only A[2,1], A[3,3], and b[1] are unknown. All other entries are fixed. The physical initial state is fixed; interior shooting values remain tunable. The MTK array a contains the two unknown entries of A. Corleone scalarizes its components during setup and stores each in its own scalar vector buffer.

    @variables begin
    x₁(t) = 0.0, [tunable = false]
    x₂(t) = 0.0, [tunable = false]
    x₃(t) = 0.0, [tunable = false]
    u(t) = 0.0, [input = true, bounds = (-3.0, 3.0)]
end
@parameters begin
    a[1:2] = [-0.2, -0.1], [tunable = true, bounds = (-0.5, -0.05)]
    b₁ = 0.5, [tunable = true, bounds = (0.1, 1.0)]
end
@constants begin
    x_t[1:3] = [3.0, 1.0, -2.0]
end


A = [0.0 1.0 0.0; a[1] 0.0 1.0; 0.0 0.0 a[2]]
b = [b₁, 0.0, 1.0]
x = [x₁, x₂, x₃]
equations = D.(x) .~ A * x + b * u
t_inf = 10.0
terminal_constraint = EvalAt(t_inf).(x) .~ scalarize(x_t)
energy = Symbolics.Integral(t in (0.0, t_inf))(0.5 * u^2)

@named lti = System(equations, t; costs = [energy], constraints = terminal_constraint)

    Shooting formulation#

    Twenty piecewise-constant input intervals share one lookup. The three unknown coefficients have no switching grid, so they remain constant over the horizon and share another lookup. Each coefficient keeps its own scalar vector buffer. Every two time units we lift all states, including the energy quadrature. Corleone adds their continuity equalities to the three terminal equalities.

    step = 0.5
starts = collect(0.0:step:(t_inf - step))
dynopt = CorleoneDynamicOptProblem(
    scalarize(lti), [], u => starts;
    algorithm = Tsit5(), tspan = (0.0, t_inf),
    shooting = collect(2.0:2.0:8.0), rng = MersenneTwister(42),
    problem_kwargs = (; abstol = 1.0e-10, reltol = 1.0e-10),
)

    Feasible initialization#
