Corleone.jl

Corleone builds differentiable shooting layers for dynamic optimization with SciML differential equation solvers and Lux parameter/state containers. Parameter switching times and per-variable initial-condition resets define the solve segments. Each evaluation returns a trajectory and updated Lux state, with matching residuals available for continuity constraints.

Installation

using Pkg
Pkg.add("Corleone")

Getting started

Start with the linear quadratic regulator or the Lotka–Volterra fishing problem. Both tutorials construct a ShootingLayer, define an optimization objective, and plot the resulting states and controls.

The manual also describes parallel shooting, tested automatic differentiation backends, and symbolic bookkeeping. Constructor and field documentation is collected in the API reference.

This manual covers the root Corleone package. Sibling packages under lib and their tutorials are outside its documentation build.
