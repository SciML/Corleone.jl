Tutorials

These examples use Corleone's shooting layers and the CorleoneOED experimental-design wrapper. All seven tutorials are executed during the documentation build.

  • Linear quadratic regulator: parameter schedules, bounded optimization, and state/control plots.
  • Lotka–Volterra fishing: single shooting, lifted initial conditions, continuity constraints, and threaded multiple shooting.
  • ModelingToolkit integration: symbolic dynamics and integral costs, metadata bounds, and single and multiple shooting with fixed global initial values.
  • LTI control with unknown coefficients: three terminal state equalities, a scalar input, three unknown constant coefficients, and shared-grid multiple shooting.

Optimal experimental design

These tutorials execute the same authoritative sources as the standalone CorleoneOED manual. See the OED overview for measurement grids, parameter directions, optimization, and numerical scope.

  • Continuous Lotka–Volterra design: jointly optimize fishing and continuous measurement densities.
  • Discrete compartmental design: allocate relaxed weights to candidate sampling events and construct a binary-weight problem description.
  • Multiple experiments: combine independent design trees in common physical coordinates and account for a global prior once.
