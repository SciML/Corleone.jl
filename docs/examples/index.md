# Optimal control tutorials

Start with **Control fundamentals** to build a shooting layer, optimize a control,
and move from single to multiple shooting. Continue with **Symbolic models and
constraints** to define dynamics as equations and estimate unknown coefficients.

Basic Julia and ordinary differential equations are enough to start. The symbolic
tutorials also introduce the ModelingToolkit interface. Each card opens an executed
Pluto notebook with plots, explanations, and a source download.
