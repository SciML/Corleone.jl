# Sublibraries

Corleone's sublibraries add experimental-design tools and a catalog of
optimal-control problems. Install the package for the task you need; each uses
the shared [shooting workflow](shooting.md).

| Package | Use it to | Start here |
|:--|:--|:--|
| CorleoneOED | Design controls and measurement schedules for local parameter estimation. | [Overview and design tutorials](oed/index.md) |
| OptimalControlBenchmarks | Prepare and solve predefined ModelingToolkit optimal-control problems with common grids and a shared driver. | [Problem catalog and first solve](benchmarks/problems.md) |

CorleoneOED's guides cover measurement conventions, design constraints, and
numerical scope. OptimalControlBenchmarks documents its problem catalog, solver
setup, and timing records alongside its API. Complete worked design problems
are collected in the [tutorial gallery](gallery/index.md).
