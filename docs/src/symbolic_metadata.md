# [Symbolic metadata](@id symbolic_metadata_guide)

Every shooting layer carries a [`ControlSymbolCache`](@ref). It wraps the problem's
SymbolicIndexingInterface provider and adds three pieces of information: which
parameters are controls, which states are quadratures, and their bounds. Controls
remain parameters and quadratures remain states, with their original indices.

```@example symbolic_metadata
using Corleone, OrdinaryDiffEqTsit5, SymbolicIndexingInterface

problem = ODEProblem((x, p, t) -> [p[1], x[1]^2],
    [1.0, 0.0], (0.0, 2.0), [0.5])
layer = ShootingLayer(problem, Tsit5(),
    Tunable(1; lowerbound = 0.0, upperbound = 1.0) => [1.0];
    controls = [1], quadratures = [2])
cache = symbolic_container(layer)
(; controls = control_symbols(cache), control_indices = control_indices(cache),
    quadratures = quadrature_symbols(cache), bounds = default_bounds(cache))
```

Get the cache with `symbolic_container(layer)` or `symbolic_container(trajectory)`;
a trajectory shares its layer's cache. The control and quadrature queries are
Corleone functions on the cache. For standard SymbolicIndexingInterface queries,
`symbolic_container(cache)` returns the wrapped provider.

## Bounds

`ShootingLayer(...; bounds = Dict(:p₁ => (0.0, 1.0)))` sets default bounds by symbol;
bounds given on an annotation take precedence. Keys must be symbols, because a bare
index could refer to either a state or a parameter. `Corleone.get_bounds(cache, symbol)`
returns one `(lower, upper)` pair, `(-Inf, Inf)` if none is set. For the bound trees
the optimizer uses, call `get_bounds(layer, ps, st)`; see
[variable bounds](@ref variable_bounds).

## Quadratures

Marking a state as a quadrature lets Corleone use its terminal value as the default
objective. It does not add any equations: the running-cost dynamics must already be
part of the model, as described in [integral costs](@ref shooting_quadratures), or be
generated by the [ModelingToolkit frontend](@ref modelingtoolkit_guide).

## Standalone caches

`ControlSymbolCache(parent; controls, quadratures, bounds)` builds a cache directly.
It keeps the parent and the bounds dictionary by reference, and `default_values(cache)`
returns the parent's mutable defaults. Changes to this shared data are visible
through the layer and its trajectories.
